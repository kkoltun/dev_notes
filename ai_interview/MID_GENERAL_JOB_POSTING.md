The general job description is:

1. Full stack mid developer with focus on backend development.
2. The application is highly concurrent and highly scalable.
3. The industry is fintech, so mistakes are expensive.
4. The developer will be making important, architectural decisions that will later be discussed and validated by
   architects.
5. The application will be run in the cloud.
6. There will be both greenfield and legacy development. In the legacy component we are using Spring, Hibernate and
   Postgres databases.
